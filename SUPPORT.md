# Support

## Getting help

1. Check [Troubleshooting](https://github.com/sukanta1991/opentelemetry#troubleshooting) in the README.
2. Search [existing issues](https://github.com/sukanta1991/opentelemetry/issues?q=is%3Aissue).
3. If nothing matches, [open a new issue](https://github.com/sukanta1991/opentelemetry/issues/new/choose) using the bug report, feature request, or question template.

## What to include in a bug report

- VS Code version and extension version
- Operating system
- OpenTelemetry SDK and language (for example the Node.js or Python SDK)
- Exporter settings: protocol (`grpc` or `http/protobuf`) and endpoint
- Steps to reproduce
- Any error messages the extension showed, and for `@otel` or `otel_*` tool issues, the output of the **OpenTelemetry AI** output channel

**Remove secrets and sensitive telemetry before you post logs or exported files.** Issues are public.

## Security issues

Do not open a public issue for a vulnerability. Follow [SECURITY.md](./SECURITY.md) instead.
